Rules use claude's format: Tool or Tool(specifier). Deny wins over ask; ask wins over allow. Rules apply from the next message. The tool name must match exactly — on Windows a shell command usually arrives as PowerShell, not Bash. The Output window logs tool_use: <name> for every call, and permission auto: … — allowed by rule: … whenever a rule decides one.
